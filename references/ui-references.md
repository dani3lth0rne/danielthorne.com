# UI Reference Sites

## Personal Site Inspiration
- https://personalsit.es — curated directory of personal sites, filterable by style
- https://minimal.gallery — minimal design showcase, lots of clean personal/portfolio sites
- https://brutalistwebsites.com — raw, expressive sites; useful as a contrast/counter-reference
- https://www.awwwards.com/websites/personal — awarded personal sites, high craft

## Portfolio / Design Work Display
- https://www.semplice.com/inspiration — portfolio-specific inspiration
- https://dribbble.com — for seeing how designers present case studies
- https://klass.studio — good example of split professional/creative identity
- https://ham.studio — editorial layout, strong typography

## Photography Presentation
- https://www.joshuajohnson.co — clean photographer portfolio, minimal chrome
- https://www.adambirdzell.com — full-bleed photography layout
- https://vsco.com — grid-based photo display patterns worth referencing
- https://www.format.com/magazine/resources/photography/photography-portfolio-websites — roundup with layout variety

## Typography & Type Systems
- https://typewolf.com — font pairings in use on real sites
- https://fontsinuse.com — typography in editorial/web contexts
- https://practicaltypography.com — foundational reference for type decisions

## Color
- https://coolors.co — palette generation and exploration
- https://www.happyhues.co — palettes shown in real UI context (very useful)
- https://colorhunt.co — curated palettes

## CSS Patterns & Technique
- https://css-tricks.com/almanac — CSS property reference with examples
- https://every-layout.dev — intrinsic/responsive layout primitives
- https://open-props.dev — CSS custom properties system, good for variable naming patterns
- https://web.dev/learn/css — structured CSS learning with modern examples

## Layout & Grid
- https://gridbyexample.com — CSS Grid patterns by Rachel Andrew
- https://ishadeed.com — deep dives into real-world CSS layout problems

## Editorial / Writing Display (for Substack content)
- https://www.are.na — how creators curate and present written work
- https://craigmod.com — strong model for a writer/photographer personal site (very relevant to your concept)
- https://www.robinsloan.com — writer with a distinct personal site voice
